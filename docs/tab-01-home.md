# 🏠 홈 탭 (Home)

> 파일: `app/home/page.tsx` · 주요 컴포넌트: `ClassRankingCard`, `ActivityCard`
> 학생 앱 하단 탭 5개 중 첫 번째 탭. 로그인 후 첫 화면.

## 1. 상단 헤더
- `Highlight` 타이틀 + 현재 시즌 부제목(`season.title`) 표시
- 우측 종 모양 버튼(🔔): **고등부 소식** 피드 모달 오픈
  - 활동 내역이 있으면 빨간 알림 점 표시
  - 모달은 하단 시트 형태(최대 75vh), 바깥 영역 터치 또는 닫기 버튼으로 종료
  - 피드 목록: DB `community_activities` 기반 최신 활동 카드(`ActivityCard`) 노출

## 2. 공지사항 (최상단)
- DB `announcements` 테이블에서 **최신 3건**만 표시
- 각 항목: 제목 + 등록일(YYYY-MM-DD), 📌 아이콘 = 중요 공지
- 클릭 시 상세 모달 오픈: 제목·내용·날짜 전문 표시, 최대 높이 80vh + 내부 스크롤
- 공지가 없으면 "등록된 공지가 없습니다." 빈 상태 표시

## 3. 내 포인트 · 레벨 카드 (Hero Card)
- 그라데이션 인디고 카드 (기존 비주얼 유지)
- **내 이름** 표시 (마일리지 대신 이름)
- 내 반 이름 표시, 반 미배정이면 "반 미배정"
- **내 달란트 잔액**(D 단위) — 학생 DB `mileage` 실시간 연동
- **내 레벨**: XP 기반 `getStudentLevel()` 계산, LV 표시
- XP 프로그레스바 + "다음 레벨까지 N D" 안내 (`getNextLevelXp`)

## 4. 랭킹 카드 (학년 / 개인)
- 탭 2개: **학년별 랭킹** / **개인 랭킹**
- **학년별**: 고1/고2/고3 별 달란트 합계 기준 내림차순 정렬
  - 교사·관리자·반 미배정 학생 제외
  - 1~3위 메달 표시(🥇🥈🥉), 내 학년은 "나" 하이라이트
  - 동률 시 학년 번호 오름차순(고1→고3)
- **개인 랭킹**: 전체 활성 학생 중 **달란트 기준 Top 10**
  - 1~3위 메달, 내 행은 인디고 하이라이트 + "나" 태그
  - 동률 시 자기 자신이 우선 표시되는 안정 정렬
- 랭킹 소스: `students` DB(전체 학생 목록) — 하드코딩 아님

## 5. 자동 일일 퀘스트
- 홈 탭 진입 시 자동으로 **d8 "홈 탭 확인"** 일일퀘스트 완료 처리 (+3D)
- DB 기반 일일 퀘스트 완료 기록으로 **하루 1회만** 적립

## 6. UX 동작
- 탭 전환 시 화면 최상단으로 자동 스크롤
- 공지/소식 모달: 바깥 영역 탭 또는 X 버튼으로 닫기, 스크롤 가능
- 로딩·빈 상태 문구 제공

## 사용 DB 테이블
| 테이블 | 용도 |
|---|---|
| `announcements` | 공지사항 목록 (홈 탭 최신 3건) |
| `community_activities` | 고등부 소식 피드 |
| `students` | 내 정보·달란트·XP·반, 개인/학년 랭킹 집계 |
| `classes` | 반 이름·레벨·XP (내 반 표시, 학년 판별) |
| `season` | 시즌 제목/기간 (헤더 부제목) |
| `daily_quests` / 퀘스트 완료 기록 | 홈 탭 확인 퀘스트 d8 |
