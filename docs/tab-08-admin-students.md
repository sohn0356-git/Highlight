# 👥 관리자 학생 관리

> 파일: `components/admin/AdminStudents.tsx`
> 관리자 앱 내비 세 번째 탭. **학생**과 **교사** 인원을 관리하는 탭.

## 1. 학생 / 교사 탭 전환
- 상단의 두 탭: **학생 목록** / **교사 목록**
- 학생과 교사를 분리해 필터링·관리

## 2. 학생 목록

### 필터
- **이름 검색** (부분 일치)
- **학년 필터**: 전체/고1/고2/고3 (반 id `_g1_/_g2_/_g3_` 패턴 판별)
- **반 필터**: 특정 반 선택
- **마일리지 정렬**: 없음 / 오름차순 / 내림차순 (달란트 기준)

### 목록 표시
- 이름, 학년·반, 달란트(D), 상세보기 화살표
- 비활성 학생은 목록에서 제외

### 학생 추가/수정
- 추가: 이름, **생년월일**, 반 선택, 전화번호(선택), 보호자 연락처(선택), 메모(선택)
- 수정: 위 항목 + **달란트 직접 조정** 입력 가능
- 저장 시 `students` DB 반영

### 학생 상세 보기
- 이름·반 헤더 (인디고 그라데이션)
- 요약 카드: **달란트**, 출석, QT 횟수, 미션 횟수, 기도 참여 횟수
- 해당 학생의 달란트 거래 내역 (`transactions`) 필터 표시
- QT/미션/기도 집계는 거래 내역 유형 기반

### 학생 삭제 (인원 삭제)
- 목록에서 삭제 버튼 → `deactivateStudent`로 **비활성 처리** (DB 반영, 즉시 목록에서 사라짐)
- 파괴적 삭제가 아닌 아카이브 방식

## 3. 교사 목록

### 교사 추가/수정
- 이름, 생년월일, **역할**(교사/관리자), **담당 반 다중 선택** (반 버튼 토글)
- 관리자(admin) 역할 지정 시 관리자 페이지 접근 가능
- 교사 반 배정 시 학생 레코드의 `class_id`/`grade`도 동기화되어 학년 랭킹·반 정보 일치

### 교사 삭제
- 삭제 버튼 → `removeTeacher`로 DB 반영
- 교사는 학생 명단 정리 대상이 아님 (보존)

### 필터
- 검색(이름), 활성 교사만 표시

## 4. DB 연동
- `students` / `teachers` 테이블 직접 CRUD — 추가·수정·삭제 모두 DB 반영, 새로고침 후 유지
- 담당 반 수정이 학년 랭킹·홈 반 정보까지 일관되게 반영

## 사용 DB 테이블
| 테이블 | 용도 |
|---|---|
| `students` | 학생 등록·반 배정·달란트·활성 상태 |
| `teachers` | 교사/관리자 등록·역할·담당 반 |
| `classes` | 반 선택 옵션 |
| `mileage_transactions` | 학생 상세 달란트 내역·활동 집계 |
