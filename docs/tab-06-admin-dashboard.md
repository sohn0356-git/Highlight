# 📊 관리자 대시보드

> 파일: `components/admin/AdminDashboard.tsx`
> 관리자 앱 좌측(데스크톱) / 하단(모바일) 내비의 첫 번째 탭.

## 1. 시즌 배너
- 시즌 이름(`season.name`), 부제목(`season.subtitle`), 기간(시작일 ~ 종료일) 표시
- 공동 목표 달란트(sharedGoalXp, K D 단위) 표시
- 인디고→바이올렛 그라데이션 카드

## 2. 빠른 작업 (Quick Actions)
- 4개 버튼 → 해당 관리 페이지로 이동:
  - **달란트 지급** → 시스템 관리(설정) 탭
  - **QT 등록** → 콘텐츠 관리 탭
  - **미션 생성** → 콘텐츠 관리 탭
  - **공지 작성** → 콘텐츠 관리 탭

## 3. 주요 통계 (DB 집계)
- **재적**: 활성 학생 수 (`students.active`)
- **오늘 출석**: 오늘 날짜 주일 세션에서 출석+지각 인원
- **이번 주 QT**: 활성 QT 개수 × 3회
- **미션 완료**: 승인된 미션 완료 건수
- **기도 참여**: 미션 완료 승인 학생 수 기반 참여자 수
- **달란트 지급**: 달란트 트랜잭션 합계(양수 금액 누계)

## 4. 반별 현황
- 전체 반 카드: 반 이름, **LV**, 담당 교사(반 배정 교사, 미배정 시 "미배정"), 인원수
- 반 총 달란트(D) + "이번 주 +N D" 성장 표시
- 클릭 시 학생 관리 탭으로 이동
- DB: `classes` + 학생 반 배정(`students.classId`) + 교사 반 배정(`teachers.assignedClassIds`)

## 5. 최근 활동
- `fetchRecentActivities()` — DB 기반 최근 활동 내역 (아이콘/내용/시간)
- 활동이 없으면 "아직 활동 내역이 없어요." 빈 상태
- 하드코딩된 샘플 활동 아님

## 6. 승인 대기 알림
- 승인 대기 중인 미션 완료(`status=pending`) 건수가 있으면 경고 배너 표시
- "승인 대기 N건 · 미션 완료 승인이 필요합니다." → 클릭 시 콘텐츠 관리 탭 이동

## 7. UX 동작
- 모든 버튼 hover/active 피드백, 카드형 레이아웃
- 모바일/데스크톱 반응형 그리드 (2열 → 3열)

## 사용 DB 테이블
| 테이블 | 용도 |
|---|---|
| `students` | 재적 수, 반별 인원, 출석 대상 |
| `attendance_sessions` / `attendance_records` | 오늘 출석 통계 |
| `qt_contents` | 이번 주 QT 수 |
| `missions` + 완료 기록 | 미션 완료/승인 대기 |
| `mileage_transactions` | 달란트 지급 합계 |
| `classes` / `teachers` | 반별 현황·담당 교사 |
| `community_activities` | 최근 활동 피드 |
| `season` | 시즌 배너 |
