# 📖 QT 탭

> 파일: `app/qt/page.tsx` · 주요 컴포넌트: `SharedQTFeed`
> 학생 앱 하단 탭 5개 중 두 번째 탭. 매일 갱신되는 오늘의 말씀(QT)을 읽고 기록하는 탭.

## 1. 오늘의 QT 본문
- DB에서 **한국 날짜(`koreaDate()`)** 기준 오늘자 QT를 조회해 표시 (`qtToday`)
- 헤더: "오늘의 QT" + 날짜 부제목 (`qtToday.date`)
- 본문 장절 파싱: 숫자로 시작하는 줄을 절 단위로 분리해 가독성 있게 렌더링
- 인용 구절(`passage`) 표시

## 2. 절 다중 선택 · 복사
- 본문의 각 절을 탭하여 **여러 절 선택** 가능
- 선택 후 복사 버튼 클릭 시 선택된 절들이 합쳐져 클립보드에 복사
- 복사 완료 시 "복사됨" 피드백 표시, 선택 초기화

## 3. QT 완료 (묵상 기록)
- 필수 입력 2개: **💡 기억나는 말씀**, **🌱 실천할 것**
- 두 입력이 모두 있어야 **완료하기** 버튼 활성화 (미입력 시 버튼 비활성 + 설명 없음)
- 완료 시 DB에 기록 저장: 1일 1회, 중복 완료 시 보상 재적립 없음
- 완료 후 해당 날짜는 완료 상태로 표시

## 4. 내 QT 기록 (모달형)
- 우측 상단 버튼으로 **기록 모달** 오픈 — 리스트 대신 모달에서 전체 기록 열람
- 기간/날짜별 기록: 날짜, 기억나는 말씀, 실천할 것
- **페이지네이션**: 5개 단위 (← 이전 / 다음 →)
- **수정**: 토글 버튼으로만 펼침(collapse), 수정 내용 저장 시 **공유 게시글에도 자동 반영**
- **삭제**: 삭제 전 확인 메시지, 삭제 시 공유 게시글도 함께 정리
  - QT를 삭제해도 해당 QT의 퀘스트는 재성공 불가 (1일 1회 규칙 유지)

## 5. QT 공유
- **공유하기**: 오늘 날짜의 내 기록을 공유 (`shared_qt_posts` DB 저장)
  - 공유 완료 시 버튼 **비활성화** (새로고침 후에도 DB 기반으로 유지)
  - 오늘 날짜가 아니면 공유 버튼 비활성화
  - 공유 취소 가능: "공유를 취소하시겠습니까?" 확인 후 내리기
  - 공유 포인트는 **하루 1회만** 지급 (삭제 후 재공유 시 포인트 없음)
- **친구들의 QT 공유 피드**: 오늘 날짜 공유 글만 노출
  - 작성자 이름·반·날짜·시간 표시
  - 본문 요약(말씀 구절/기억/실천), **댓글 수** 표시
  - 댓글: 작성 가능, 내 댓글은 **수정/삭제** 가능, 시간 함께 표시
- 공유 여부·댓글 모두 DB(`shared_qt_posts`, 댓글 테이블)에 저장되어 새로고침·재로그인 후에도 유지

## 6. UX 동작
- 장절 선택/복사, 공유, 기록 모달 등 모든 인터랙션 DB 연동
- 기록 모달 collapse는 토글 버튼으로만 펼침/접힘 (본문 클릭 시 닫히지 않음)

## 사용 DB 테이블
| 테이블 | 용도 |
|---|---|
| `qt_contents` | 오늘자 QT 말씀 (제목/본문/인용구/날짜) |
| QT 완료 기록 | 사용자+날짜 기준 완료/답변 저장, 중복 보상 방지 |
| `shared_qt_posts` | 공유 글 (작성자·날짜·내용·공유 여부) |
| QT 공유 댓글 | 공유 글 댓글 (작성자·시간·내용) |
| `mileage_transactions` | QT/공유 보상 적립 내역 |
| 일일 퀘스트 완료 | d2 QT 완료, d4 공유 퀘스트 자동 처리 |
