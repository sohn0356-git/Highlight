# 📅 관리자 출석 관리

> 파일: `components/admin/AdminAttendance.tsx`
> 관리자 앱 내비 두 번째 탭. **주일 출석 체크**와 **출석 기록 조회** 두 화면으로 구성.

## 1. 주일 출석 체크 (Check View)

### 주 단위 네비게이션
- 선택된 주일(Sunday) 기준 주간 이동: ◀ 이전 주 / 다음 주 ▶
- **몇 주차인지** 표시 (`getWeekNumber`, 올해 기준) + 날짜 범위 표시 (월~일)
- 기준 날짜는 `getSunday()`로 **한국 시간 기준 정확한 주일** 계산

### 반 필터
- "전체 반" 또는 특정 반 선택 → 해당 반 활성 학생만 표시

### 출석 세션
- 선택 주의 세션이 없으면 안내 문구 ("출석 체크를 시작하면 세션이 자동 생성됩니다")
- 첫 체크 시 **세션 자동 생성**: `addAttendanceSession` (주일예배, 10:00~12:00, 활성, 출석 보상 20D)
- 세션당 학생별 상태 1개 저장 (`attendance_records`)

### 학생별 출석 상태 표시
- 활성 학생 목록(반 필터 적용): 이름 첫 글자 아바타, 이름, 반 이름
- 상태 버튼 4종 중 **선택된 상태 하이라이트**:
  - ✅ 출석(present, 초록) / ⏰ 지각(late, 노랑) / 💻 온라인(online, 파랑) / ❌ 결석(absent, 빨강)
- 버튼 클릭 시 즉시 DB 저장 (`markStudentAttendance`)
- 상단 요약: `N명 · M명 출석` (출석+지각 기준)

## 2. 출석 기록 조회 (History View)

### 월별 / 연별 모드
- **월별**: N년 N월 기준 — 이전 달/다음 달 이동 시 연도 자동 전환 (12월→내년 1월, 1월→작년 12월)
- **연별**: N년 기준 — 이전/다음 연도 이동
- **이전 달(연) 기록도 모두 열람 가능**

### 기간 요약
- 출석 / 지각 / 온라인 / 결석 4종 카운트 합계 카드

### 학생별 출석 횟수
- 활성 학생 각각에 대해 해당 기간(월 또는 연)의 **출석 횟수** 표시
- 집계 기준: `present`·`late`·`online` 상태를 출석으로 카운트, 세션 날짜로 기간 판별
- 반 이름 병기, 기록이 없으면 0회

## 3. DB 연동
- 모든 체크/집계가 `attendance_sessions` + `attendance_records` DB 기반
- 새로고침 후에도 선택 주의 출석 상태·기록 유지

## 사용 DB 테이블
| 테이블 | 용도 |
|---|---|
| `attendance_sessions` | 주일예배 세션 (날짜·시간·활성·보상) |
| `attendance_records` | 학생별 세션 상태 (출석/지각/온라인/결석) |
| `students` | 출석 대상 (활성 학생, 반 필터) |
| `classes` | 반 이름 표시 |
| `mileage_transactions` | 출석 20D 적립 (출석 체크 시) |
