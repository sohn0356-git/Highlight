# ⚙️ 관리자 시스템 관리

> 파일: `components/admin/AdminManagement.tsx`
> 관리자 앱 내비 다섯 번째 탭. 달란트·상점·배지·통계·기록·설정을 관리하는 탭.

## 1. 달란트 (지급/차감)
- **대상 선택**: 학생 / 반 / 학년(1·2·3) / 전체
  - 학생 선택 시 활성 학생 드롭다운, 반 선택 시 반 드롭다운, 학년 선택 시 1/2/3 옵션
- **금액(D)** 입력, **지급/차감** 유형 선택
- **사유 필수** 입력
- **지급 버튼 클릭 시 확인 다이얼로그**: 대상·금액·지급/차감 여부를 한 번 더 확인
- 확인 후 `awardsMileage` 실행 — 학생/반/학년/전체 대상 **개별 DB 트랜잭션**으로 달란트 반영
- 완료 시 감사 로그 추가 (`addAuditLog`, 유형 mileage_award)
- 내역: "달란트 내역" 패널(전체 N건) 열기/닫기 → 최근 20건 역순 표시 (이름·설명·+N D·날짜)

## 2. 상점 (보상 관리)
- **보상 추가/수정**: 이름, 설명, 달란트 비용, 재고(inventory), 카테고리(예: 교환권)
- 보상 목록: 이름·설명·비용·재고, 활성/비활성 배지, 수정/삭제
  - 삭제 시 confirm 후 **비활성화**(active=false)
- **신청 대기 관리**: 학생의 상점 신청(신청됨) → **승인 / 취소** 버튼
- **신청 내역**: 전체 신청 목록 (학생 · 상품 · 날짜 · 상태: 신청됨/승인됨/수령완료/취소됨)

## 3. 배지
- 배지는 **시스템 자동 관리** (별도 추가 기능 없음)
- 배지 목록 카드 표시: 아이콘, 이름, 설명, **레벨 임계값**(예: 1 / 3 / 5 …)
- 레벨/임계값은 DB 배지 정의 기반

## 4. 통계
- 카드형 지표:
  - 주간 출석률 · QT 참여율 · 미션 참여 · 기도 참여 (전주 대비 증감 표기)
  - **달란트 지급** (양수 합계, 이번 달) · **달란트 사용** (음수 합계 절댓값, 이번 달)
- **반별 D**: 반별 총 달란트 내림차순 정렬 + D 기준 비율 프로그레스바

## 5. 기록 (달란트 내역 전체)
- 전체 달란트 거래 내역 (건수 표시, 최대 높이 600px 스크롤)
- 각 항목: 학생 아바타(첫 글자), 학생 이름, 설명 · 유형, **+/−N M**, 날짜
- 누가·언제·어떻게 포인트를 받았는지 DB(`mileage_transactions`) 기반 표시

## 6. 설정
- **기본 달란트 설정**:
  - 기본 출석 달란트 · 기본 QT 달란트 · 기도 참여 달란트 · 주간 미션 기본 보상 (D 단위, 숫자 입력 즉시 저장)
- **앱 설정 토글**:
  - 익명 기도 활성화 · 달란트 상점 활성화 (스위치 토글)
- **데이터 초기화 (주의)**:
  - "모든 관리자 데이터를 샘플 데이터로 초기화합니다" 경고 문구
  - confirm 확인 후 `resetToSeedData()` 실행 (되돌릴 수 없음)

## 7. DB 연동
- 달란트 지급/차감, 상점 승인/취소, 배지, 통계, 기록, 설정 모두 DB 기반
- 새로고침·재로그인 후에도 모든 변경사항 유지

## 사용 DB 테이블
| 테이블 | 용도 |
|---|---|
| `students` / `classes` | 달란트 지급 대상 선택 |
| `mileage_transactions` | 달란트 적립/차감 내역 (지급·사용 합계) |
| `rewards` | 상점 상품 (비용·재고·카테고리·활성) |
| `redemptions` | 상점 신청 (상태: 신청/승인/수령/취소) |
| `badges` (+레벨 정의) | 배지 목록·임계값 표시 |
| `audit_logs` | 관리자 달란트 지급 등 감사 기록 |
| `settings` | 기본 보상 값·앱 토글 |
