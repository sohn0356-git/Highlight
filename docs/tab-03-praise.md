# 💛 칭찬 탭

> 파일: `app/praise/page.tsx`
> 학생 앱 하단 탭 5개 중 세 번째 탭. 고등부 구성원(학생+교사)을 칭찬하고 피드를 보는 탭.

## 1. 칭찬 등록
- **칭찬할 친구 선택**: 이름 검색 → 대상 목록에서 선택
  - 대상 = 활성 학생 전체 + **활성 교사** (교사도 칭찬 가능)
- **칭찬 이유** 필수 입력 (텍스트 영역)
- **익명으로 칭찬하기** 체크 가능 — 피드에 "익명"으로 표시
- **하루 1회 제한**: DB `praises.date` 컬럼 기준, 같은 날 중복 등록 불가
  - 중복 등록 시도 시 즉시 차단 (이미 칭찬한 날로 처리)
- 등록 버튼: "+5D" 표기, 등록 중 로딩 스피너 표시, 중복 클릭 방지

## 2. 칭찬 보상 (달란트)
- **칭찬받은 사람**: +10D
- **칭찬한 사람**: +5D
- `students.mileage` 즉시 반영 + `mileage_transactions`에 기록 (유형 "칭찬", 날짜 포함)
- 칭찬 시 **d9 일일퀘스트** 자동 완료 (하루 1회)
- DB 저장 성공 후에만 화면 갱신 (낙관적 오류 없음)

## 3. 칭찬 피드
- DB `praises` 테이블 최신순(created_at DESC) 최대 50건 조회
- 카드 구성:
  - 칭찬자 아바타(첫 글자, 익명이면 `?`) → 칭찬 대상 이름
  - 익명 여부, 날짜(월/일/요일)
  - "+10D" 보상 배지, 칭찬 이유 전문
- **페이지네이션**: 5개 단위 (← 이전 / 다음 →)
- 빈 상태: "아직 칭찬이 없어요. 첫 칭찬을 남겨보세요!"

## 4. UX 동작
- 입력 폼 열기/닫기 토글 (grid 애니메이션)
- 등록 완료 시 폼 초기화 + 피드 즉시 갱신
- 로딩 상태 표시 ("칭찬 불러오는 중...")

## 사용 DB 테이블
| 테이블 | 용도 |
|---|---|
| `praises` | 칭찬 기록 (칭찬자/대상/사유/익명/날짜, 하루 1회 제한) |
| `students` | 칭찬 대상 목록, 달란트 잔액 |
| `teachers` | 교사 칭찬 대상 (활성 교사) |
| `mileage_transactions` | +10D/+5D 적립 내역 |
| 일일 퀘스트 완료 | d9 칭찬 퀘스트 |
