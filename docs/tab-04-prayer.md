# 🙏 기도 탭

> 파일: `app/urinae/page.tsx` · 주요 컴포넌트: `PrayerCard`
> 학생 앱 하단 탭 5개 중 네 번째 탭. 기도제목을 올리고 서로 기도하며 댓글로 나누는 탭.

## 1. 기도제목 목록
- DB `prayers` 테이블 기반, **최신순** 정렬
- **필터**: 전체 / 내 글
- **검색**: 제목(내용) 기준 키워드 검색
- **페이지네이션**: 5개 단위 (← 이전 / 다음 →)
- 빈 상태: "아직 기도제목이 없어요.", 검색 결과 없음 안내

## 2. 기도제목 등록
- 내용 입력 + **익명으로 남기기** 체크 가능
- 등록 시 DB에 저장 → 목록 최신순 상단에 표시
- **여러 개 등록 가능** (하루 1개 제한 없음)
- 등록 완료 시 폼 닫힘 + 데이터 재로드

## 3. 기도했어요 버튼 (하루 1회)
- 각 기도제목 카드의 **🙏 기도했어요** 버튼
- **기도제목별로 하루 1회** 클릭 가능 — 누르면 즉시 비활성화(낙관적 UI, 버퍼링 없음)
- 클릭 시 `prayer_participants`에 사용자+날짜 기록 저장
- **자기 기도제목에 기도하면 마일리지/퀘스트 미적립** (본인 글 보상 제외)
- 다른 친구 기도를 실제로 기록한 경우에만 **d5 일일퀘스트** 완료 (10D)
- 전체 리패치 없이 로컬 참가자 목록 즉시 갱신, 서버 동기화는 DB 저장으로 보장

## 4. 기도한 친구 모달
- 카드 우측 상단 버튼: **🙏 인원수** 표시 (누른 사람 수)
- 클릭 시 모달 오픈: **총 N명** + 기도한 친구 목록
- 각 친구: 이름 + **기도 횟수** (totalPrayerCount) — **많이 기도한 순(내림차순)** 정렬
- 바깥 영역 터치 또는 X(닫기) 버튼으로 닫기

## 5. 기도제목 댓글
- 각 기도제목에 **댓글** 작성 가능 → DB(`prayer_comments`) 즉시 저장
- 낙관적 반영으로 화면에 바로 표시 (전체 리패치 없음)
- **댓글 수** 표시

## 6. 내 글 관리
- 내가 올린 기도제목: **수정**(이름·날짜 유지, 내용 변경) 및 **삭제** 가능
- 삭제는 확인 후 진행 (2단계 확인: 휴지통 → 체크)
- 수정/삭제 시 DB 반영 후 화면 갱신

## 7. UX 동작
- 버튼 클릭 시 카드가 위아래로 흔들리지 않도록 **최소 재렌더 + 낙관적 상태 관리**
- 댓글·참가자·기도여부 데이터는 한 번에 일괄 조회해 과도한 로딩 방지

## 사용 DB 테이블
| 테이블 | 용도 |
|---|---|
| `prayers` | 기도제목 (작성자/내용/익명/날짜) |
| `prayer_participants` | 기도 눌렀을 때 사용자+날짜 기록 (하루 1회, 횟수 집계) |
| `prayer_comments` | 기도제목 댓글 (작성자/시간/내용) |
| `students` | 작성자 이름 표시 |
| `mileage_transactions` | 기도 보상 적립 (본인 글 제외) |
| 일일 퀘스트 완료 | d5 기도 퀘스트 |
