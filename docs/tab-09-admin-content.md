# 📝 관리자 콘텐츠 관리

> 파일: `components/admin/AdminContent.tsx`
> 관리자 앱 내비 네 번째 탭. **미션**과 **공지** 두 콘텐츠를 관리하는 탭.

## 1. 미션 관리

### 미션 등록
- "미션 등록" 버튼 → 폼 오픈 (닫기/재클릭 시 입력값 초기화, 캐시 남지 않음)
- 입력 항목:
  - **제목** (필수)
  - **설명**
  - **아이콘** (이모지)
  - **유형**: 주간(weekly) / 스페셜(special) / 이벤트(event) / 반별(class-only)
  - **획득 포인트**: 달란트(D) 1개 값만 입력 (마일리지·XP 따로 입력하지 않음)
  - **대상**: 전체 / 고1 / 고2 / 고3 / 직접 지정(custom)
  - **승인 필요** 여부 (학생 제출 → 교사 승인 방식)
- 시작/끝 날짜 입력 없음 (단순 등록)
- 등록 즉시 DB `missions` 저장 → **학생 앱 프로필 탭에 바로 반영**

### 미션 수정 / 삭제
- 목록의 각 미션: **수정**(폼에 기존 값 채워 넣기) / **삭제**
- 삭제 시 confirm 확인 후 `active=false` 처리 (비활성화, 실제 삭제 아님)
- 목록 항목: 아이콘, 제목, 유형·보상(D), 활성/비활성 상태 배지

## 2. 공지 관리

### 공지 작성
- "공지 작성" 버튼 → 폼 오픈
- 입력 항목:
  - **제목** (필수)
  - **내용** (여러 줄)
  - **중요 공지로 표시** 체크 (학생 홈에서 📌 강조)
- 작성 시 DB `announcements` 저장: 시작일 = 오늘, 종료일 = 오늘+30일, status = published
- **대상 설정 없음** (전체 대상), 학생 홈 탭 공지사항에 즉시 반영

### 공지 수정 / 삭제
- 목록 항목: 제목, 내용 미리보기(1줄), 상태 배지(게시중), **수정** / **삭제** 버튼
- 수정 시 기존 값 채워진 폼으로 편집
- 삭제 시 confirm 확인 후 `status=ended` 처리 (게시 종료)

## 3. DB 연동
- 미션·공지 모두 `missions` / `announcements` 테이블 CRUD
- 저장 성공 후 학생 앱(프로필 탭 미션, 홈 탭 공지)에 실시간 반영

## 사용 DB 테이블
| 테이블 | 용도 |
|---|---|
| `missions` | 미션 정의 (제목·설명·유형·보상·대상·승인 필요·활성) |
| `announcements` | 공지 (제목·내용·중요·기간·상태) |
| 미션 완료 기록 | 학생 완료 상태·승인 대기 |
