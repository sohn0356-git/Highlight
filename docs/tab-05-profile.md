# 👤 프로필 탭

> 파일: `app/my/page.tsx` · 주요 컴포넌트: `BadgeCard`
> 학생 앱 하단 탭 5개 중 다섯 번째(마지막) 탭. 레벨·퀘스트·미션·배지·계정 관리를 한곳에 모은 탭 (기존 미션 탭 기능 통합).

## 1. 내 레벨 · 달란트 카드
- 그라데이션 인디고/퍼플 카드 (기존 비주얼 유지)
- **내 레벨**: XP 기반 `getStudentLevel()` — LV 표시, "총 N D"
- **내 달란트 잔액**(D 단위) — 학생 DB `mileage` 실시간 연동
- XP 프로그레스바: LV.N → LV.N+1 구간, "N D 남음" 표시
- 반 경험치(클래스 XP)는 표시하지 않음

## 2. 오늘의 퀘스트
- DB 기반 일일퀘스트 목록: 아이콘, 제목, 설명, 보상(+N D)
- 완료 상태 표시: 완료 시 에메랄드 배경 + ✅ "달성 완료!"
- 진행률: `완료 수 / 전체 수` 카운트 + 프로그레스바
- **자동 완료형**: QT 완료, 공유, 기도, 칭찬, 홈 확인 등 활동 시 자동으로 완료 (하루 1회)

## 3. 미션 (관리자 등록분)
- 관리자 페이지에서 등록한 **모든 활성 미션 표시** (스페셜 포함)
- 미션 카드: 아이콘, 제목, 설명, 보상(+N D), 완료 여부
- 완료 시 ✅, 미완료 시 "⏳ 진행 중"
- DB 없는 임시/더미 미션은 표시하지 않음

## 4. 배지 컬렉션 (DB 기반)
- `fetchStudentBadgesWithProgress()`로 **실제 활동 기록 기반 배지 진행도** 조회
- 각 배지 카드(`BadgeCard`):
  - 배지 아이콘·이름, **현재 레벨 타이틀**(예: 말씀새싹)
  - Lv 표시(1~10) 또는 **Lv.MAX**(최고 레벨 도달 시에만)
  - 진척도: `현재 수 / 다음 레벨 기준치` + **남은 수 안내** (예: "QT 5회 더 완료")
  - 프로그레스바 + 레벨별 배경색
  - 미획득 배지는 잠금 아이콘 + 회색 처리
- 배지 구성(카테고리): 말씀 읽기(QT 횟수), 중보기도(기도 횟수), 꾸준한 QT(연속 QT), 칭찬하기(칭찬 횟수), 퀘스트(퀘스트 완료 횟수), 달란트(누적 달란트) 등 — DB `badges` 정의 기반

## 5. 관리자 페이지 진입
- `role === "admin"` 사용자에게만 **관리자 페이지** 버튼 표시
- 클릭 시 앱이 관리자 모드로 전환 (`setMode("admin")`)
- 관리자 전용 페이지: 학생/출석/미션/달란트 관리

## 6. 로그아웃
- 하단 로그아웃 버튼: 확인 후 세션 종료 + 페이지 새로고침
- **반 정보가 없어도 항상 로그아웃 가능**

## 7. UX 동작
- 배지 로딩 스피너, 빈 상태 처리
- 새로고침·재로그인 후에도 레벨·퀘스트·미션·배지 상태 DB에서 복원

## 사용 DB 테이블
| 테이블 | 용도 |
|---|---|
| `students` | 이름·레벨·달란트·XP·역할(admin 여부) |
| `daily_quests` / 완료 기록 | 오늘의 퀘스트 목록·완료 상태 |
| `missions` (+활성 여부) | 관리자 등록 미션 표시 |
| `badges` + 배지 레벨 정의 | 배지 종류·레벨 임계값 |
| 활동 원장(QT/기도/칭찬/퀘스트/달란트) | 배지 진행도 실집계 |
